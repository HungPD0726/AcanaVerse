# ArcanaVerse

ArcanaVerse is a bilingual (Vietnamese/English) Tarot web application built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, Motion, Web Audio API, and `next-intl`.

Inspired by the elegant **Moonlight.world** aesthetic, ArcanaVerse features:
- 🌌 **Moonlight Dark Space Glow & Neo-Brutalist 3D UI**
- 🎴 **Digital Decks Explorer (`/decks`) with 3D Fanning Deck Cards**
- 📜 **600-Year Tarot History & Purpose Page (`/about`)**
- 🔀 **3D Deck Tilt, Cascading Vertical Shuffle, and Wave Arc Fan**
- 🔮 **Structured AI Deep Insight & Classic Interpretation Engine**
- 🎵 **Synthesized Web Audio Engine & Ambient Tibetan Singing Bowl (432Hz)**
- 📓 **Tarot Journal & Exportable PNG Reading Summary Cards**

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The root route redirects to Vietnamese at `/vi`; English is available at `/en`.

## Verification Checks

```bash
npm run typecheck
npm test
npm run build
```
